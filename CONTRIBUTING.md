# Contributing

Amethyst Messenger is a preservation project. Keep patches focused and retain the Pidgin 2.11.0 GTK2 experience, libpurple ABI, protocol IDs, and historical Windows support.

For Windows work, follow [the pinned build instructions](docs/BUILD-WINDOWS.md). Include the exact compiler and target, the affected OS, commands used, and whether a result was built, statically checked, run under Wine, or run on the target Windows release. Do not include passwords, access tokens, private profile data, or machine-specific files in commits.

Retain copyright and license notices from upstream and bundled components. New artwork should be original or have a clearly documented license. For changes affecting MSN, test with CrossTalk and distinguish server-side behavior from client changes.

Issues and contributions: https://github.com/ProjectCrystalROM/AmethystMessenger/issues
