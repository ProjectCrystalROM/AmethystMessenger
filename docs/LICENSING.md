Amethyst Messenger is derived from Pidgin 2.11.0. The source tree retains the upstream `COPYING`, `COPYRIGHT`, `AUTHORS`, and file-level notices. Pidgin and libpurple are licensed under the GNU GPL version 2 or, at the recipient's option, any later version, as specified in `COPYING`.

The Windows package includes msn-pecan source integrated under `libpurple/protocols/msn/`, its retained copyright notices, `COPYING`, and its bundled libmspack `COPYING.LIB`. It also includes tdlib-purple source under `third_party/tdlib-purple/`, licensed GPL-2.0-or-later, with its notices retained. TDLib, OpenSSL 3, fmt, and zlib are statically linked into that plugin; their license texts are installed under `Licenses/`, and their exact source revisions are supplied in the Telegram third-party source archive.

The Discord plugin source under `third_party/purple-discord/` is GPL-3.0-or-later. Its QR login code uses the OpenSSL crypto backend, statically linked for QR authentication. QRencode 4.1.1 (LGPL-2.1) is also statically linked; JSON-GLib 0.14.2 (LGPL-2.1) is provided as a separate runtime DLL. The Windows installer retains both LGPL license texts and includes the exact JSON-GLib and QRencode source archives, verified against the hashes in `third_party/sources/SHA256SUMS-discord`. The upstream plugin license and source are included as well.

The package also reuses the official Pidgin 2.11.0 Windows runtime for GTK2 and existing dependencies and protocol plugins. Their names and licenses are retained in the distribution where available. The source tree and build scripts do not replace those upstream component terms.

Windows dependencies include GTK+/GLib and related components, GTKSpell/Enchant, libxml2, NSS/NSPR, SQLite, and other upstream Pidgin runtime modules. Consult the corresponding upstream license and source distributions for each exact runtime version. The historical Pidgin Windows packaging recipes and pinned inputs are documented in `pidgin/win32/` and `docs/BUILD-WINDOWS.md`. Exact GTK and other runtime source locations are listed in [THIRD-PARTY-SOURCES.md](THIRD-PARTY-SOURCES.md).
